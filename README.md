# stratios-map

Δεδομένα χάρτη (OpenStreetMap) για την περιοχή Πιερίας, βόρειας Λάρισας (έως Τέμπη/Ευαγγελισμό), Ημαθίας (έως Αλεξάνδρεια) και Θεσσαλονίκης (έως είσοδο πόλης).
Πλαίσιο: δυτικά 22.05, νότια 39.80, ανατολικά 23.00, βόρεια 40.72 — μέγιστο zoom 15.

Το αρχείο PMTiles είναι σπασμένο σε κομμάτια των 4 MB (`region-000.bin` …) και περιγράφεται στο `region.json`.

Πηγή: Protomaps basemap build 2026-10-10 (https://protomaps.com), που βασίζεται σε δεδομένα OpenStreetMap.
