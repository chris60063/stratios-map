# stratios-map — ανάγλυφο (relief1)

Υψόμετρα εδάφους για το ανάγλυφο του χάρτη, για την περιοχή από τους Ευζώνους έως το Κιλελέρ / Μοσχοχώρι Λάρισας.
Πλαίσιο: δυτικά 22.05, νότια 39.35, ανατολικά 23.00, βόρεια 41.15 — zoom 0–12, πλακίδια WebP 512 px (κωδικοποίηση «terrarium»,
υψόμετρα στρογγυλεμένα στο 1 μέτρο).

Το αρχείο PMTiles είναι σπασμένο σε κομμάτια του 1 MB (`relief-000.bin` …) και περιγράφεται στο `relief.json`.
